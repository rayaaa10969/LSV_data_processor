# LSV Lab

无需第三方依赖的浏览器端 LSV 数据处理应用。所有上传文件只在设备本地处理。

运行：`node server.mjs`，访问 http://127.0.0.1:5173 。运行全部测试：`node --test tests/*.test.mjs`。npm 可用时也支持 `npm start` 与 `npm test`。
也可以将 dist 目录发布到任意静态网站托管。

测试使用 Node.js 内置测试工具，无需安装依赖。覆盖文件解析、手算样本的基线与 iR 补偿、Tafel 近零阈值、参数校验、TXT 完整导出，以及 Vercel 静态构建成功和缺失文件失败的场景。构建测试在临时目录执行，不修改实际部署产物。这些测试不包含浏览器交互或线上部署验证。

导入逗号分隔的 TXT/CSV，填写电压修正值 V、电极面积 S（cm²）和溶液电阻 Rs（Ω），点击开始处理。分别下载原文件名_处理后.txt 与原文件名Tafel.txt。

项目工作区支持选择整个实验目录，按文件名初步区分原始 LSV、EIS、CV 和已有处理结果；可编辑样品名/测试标签，选择多条 LSV 并使用当前参数批量处理。`.lsvproj` 是带版本号的 JSON 项目文件，保存导入文件、相对路径、样品分组、参数、LSV/Tafel 结果、EIS 截点和 10/100/1000 mA 的 HER 记录。移除文件先暂存在当前工作区，保存项目时才从新下载的项目文件中排除。网页不使用浏览器缓存保存项目。

Origin TXT 使用制表符分隔，包含 Long Name、Units、Comments 三行列标签；每条曲线占 Potential 与 Current density 两列，数据行数不同时补空单元格。导入 Origin 后按相邻列选择 X/Y。结果汇总另可导出 CSV。批量处理会把当前电压修正、面积和 Rs 应用于所有勾选 LSV；需要不同参数的文件请分别打开并处理后保存项目。

计算严格遵循原脚本的实际代码：C=A+V，D=B×1000/S，取 |C| 最小的首行 k，E=D−D[k]，F=C−Rs×E×S/1000。Tafel TXT 按作图顺序输出 log10|E|（X 轴）与 −F（Y 轴）。|E|<1e-15 时输出 -inf。没有线性拟合功能。

与原脚本相比，额外拒绝非有限数值、负电阻以及非正电极面积。参数修改后须重新计算，避免导出旧结果。预览显示前 100 行，图表最多约 4000 点；导出始终包含全部数据。文件大小限制 20 MB。
