# LSV Lab

无需第三方依赖的浏览器端 LSV 数据处理应用。所有上传文件只在设备本地处理。

运行：`node server.mjs`，访问 http://127.0.0.1:5173 。运行全部测试：`node --test tests/*.test.mjs`。npm 可用时也支持 `npm start` 与 `npm test`。
也可以将 dist 目录发布到任意静态网站托管。

测试使用 Node.js 内置测试工具，无需安装依赖。覆盖文件解析、手算样本的基线与 iR 补偿、Tafel 近零阈值、参数校验、TXT 完整导出，以及 Vercel 静态构建成功和缺失文件失败的场景。构建测试在临时目录执行，不修改实际部署产物。这些测试不包含浏览器交互或线上部署验证。

导入逗号分隔的 TXT/CSV，填写电压修正值 V、电极面积 S（cm²）和溶液电阻 Rs（Ω），点击开始处理。分别下载原文件名_处理后.txt 与原文件名Tafel.txt。

项目工作区可导入整个实验目录或多个 TXT/CSV 文件，每次导入归入一个样品。样品名支持搜索已有样品；选中已有样品会复用 `sampleId`，并自动取下一个测试组序号。测试组号不从文件名推测，避免将扫描速率或电压误当组号。每个测试组保存整数序号、酸碱性（H、OH 或中性）、面积（cm²）和温度（°C）；LSV、EIS、CV 和处理结果通过稳定的 `sampleId`、`testGroupId` 关联。项目文件结构版本为 3，旧版本 1、2 会在打开时迁移。项目内 EIS 分析结果（包括 Rs、Rct 和截点）保存在对应 EIS 记录中，LSV 处理页可从同测试组选择并填入 Rs；不同文件仍逐条设置参数。独立 LSV 处理页与项目 LSV 工作页分开，独立处理的结果可直接导出，也可选择把原始数据和结果或仅结果保存到项目。

项目变化会自动保存到浏览器 IndexedDB，刷新后从最近使用的项目恢复；此本机工作副本受浏览器配置、清理站点数据和存储配额影响。`.lsvproj` 是带版本号的 JSON 项目文件，可手动打开或另存为便携副本，与 IndexedDB 使用相同项目结构。移除文件先暂存在当前工作区，保存项目文件时才从项目中删除。导入预览是临时状态，不单独持久化。

Origin TXT 使用制表符分隔，包含 Long Name、Units、Comments 三行列标签；每条曲线占 Potential 与 Current density 两列，数据行数不同时补空单元格。导入 Origin 后按相邻列选择 X/Y。结果汇总另可导出 CSV。

计算严格遵循原脚本的实际代码：C=A+V，D=B×1000/S，取 |C| 最小的首行 k，E=D−D[k]，F=C−Rs×E×S/1000。Tafel TXT 按作图顺序输出 log10|E|（X 轴）与 −F（Y 轴）。|E|<1e-15 时输出 -inf。没有线性拟合功能。

与原脚本相比，额外拒绝非有限数值、负电阻以及非正电极面积。参数修改后须重新计算，避免导出旧结果。预览显示前 100 行，图表最多约 4000 点；导出始终包含全部数据。文件大小限制 20 MB。
